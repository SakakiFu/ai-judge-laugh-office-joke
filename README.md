A one-line entry for the make.fun bounty [Make the AI Judge Laugh](https://make.fun/bounty/u-rama-melon-make-the-ai-judge-laugh-302d0825): a single joke about office life, one line, under 200 characters.

The joke:

> I put 'per my last email' in my email signature, so now every email I send is technically a sequel.

## Run it

```
node main.ts
```

This writes the joke to `entry.txt` in `MAKEFUN_OUTPUT_DIR` when that variable is set, and in this directory otherwise, then reads the file back and checks the bytes match. Running it twice produces byte-identical output.
